# Wiki 发布步骤

1. 登录你自己的 GitHub，进入 https://github.com/sjj124390/-/wiki 。
2. 点击 New Page，标题填写 `阶段性成果验收`，编辑格式选 Markdown。
3. 打开本目录 `阶段性成果验收.md`，点击 Raw 或复制文件内容按钮，将全文粘贴到 Wiki 正文，点击 Save Page。
4. 再新建页面，标题填写 `第1次成果验收`，复制本目录 `第1次成果验收.md` 的全文并保存。
5. 回到 `阶段性成果验收`，点击“第1次成果验收”确认能跳转，逐项点开成果物链接。
6. 将 `阶段性成果验收` 首页的地址发给老师指定的智能助教。不要仅提交源码仓库地址，也不要自行修改老师仓库中其他小组的验收记录。

两份 Markdown 的标题固定，不能只把它们留在普通代码仓库：必须按上述步骤在 Wiki 中创建同名页面，才能符合模板的定位规则。

发布前请确认本次确实按“基线需求”提交；口令码是已实现扩展，但现有信息不足以认定对应挑战 A/B/C/D/E 的哪一项。若老师要求某项挑战需求，应先核对其原文再修改验收需求字段。

本次准备完成五类材料目录，并不代表所有需求均已满足。自动冻结、自动补货、服务端鉴权和自动化录屏证明的待办见验收子页与需求对照。
