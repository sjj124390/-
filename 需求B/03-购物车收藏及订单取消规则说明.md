## 1. 购物车规则

### 1.1 加入购物车

| 编号 | 规则 |
| --- | --- |
| C-01 | 仅"在售"商品可加入购物车；已售出、已下架、已锁定商品加入时提示"商品当前不可购买" |
| C-02 | 二手单品数量恒为 1，无数量编辑；重复加入同一商品时提示"已在购物车中"，不产生重复记录 |
| C-03 | 加入购物车**不锁定商品**，仅记录客户预选意向；商品仍可被其他客户购买 |
| C-04 | 客户不能加入自己发布的商品 |
| C-05 | 购物车容量上限 50 件，超出时提示先清理再添加 |

### 1.2 购物车展示与维护

| 编号 | 规则 |
| --- | --- |
| C-06 | 购物车按商家分组展示，组内按加入时间倒序；支持单选、全选（按组/全表）、移除 |
| C-07 | 商品被他人买走或被商家下架后，购物车中该项自动标记"失效"：不可勾选、置灰展示，可一键清除失效项 |
| C-08 | 商品价格被商家修改后，购物车展示最新价格并标注"价格已变动" |
| C-09 | 客户登录状态下购物车数据持久化；未登录仅可浏览，加购时引导登录 |

### 1.3 多选下单（B.2 核心规则）

| 编号 | 规则 |
| --- | --- |
| C-10 | 客户可勾选**多件商品一次提交下单**；提交时系统**重新校验**所有选中商品状态，失效商品自动剔除并提示，客户确认后继续 |
| C-11 | 选中商品分属不同商家时按商家**拆单**：每个商家生成一张独立订单，独立流转、独立取消 |
| C-12 | 订单创建成功即**锁定**商品（防一物多卖）；锁定期间其他客户不可加购/下单 |
| C-13 | 下单成功的商品自动从购物车移除；未选中的商品保留 |
| C-14 | 订单取消后商品自动解锁恢复在售，**不自动回到购物车**，客户需重新加购 |

### 1.4 多选转收藏（B.2 核心规则）

| 编号 | 规则 |
| --- | --- |
| C-15 | 客户可勾选**多件商品批量"转为收藏"**：系统批量写入收藏夹，并将对应商品从购物车移除 |
| C-16 | 选中商品中已收藏的自动跳过，不重复写入、不重复计数；失效商品不参与转收藏并提示 |
| C-17 | 批量转收藏为幂等操作，重复提交结果一致；转收藏不影响商品在售状态 |
| C-18 | 收藏夹商品可直接"加入购物车"（商品在售且未被锁定时），形成购物车与收藏夹双向联动 |

## 2. 收藏规则

| 编号 | 规则 |
| --- | --- |
| F-01 | 客户对商品可收藏/取消收藏，操作**幂等**：重复收藏不重复计数，重复取消不报错 |
| F-02 | 商品详情与商品卡片心形图标状态实时同步；商品详情展示收藏人数（如"已收藏 24 人"），随操作实时增减 |
| F-03 | 收藏夹按收藏时间倒序展示，支持按商品分类筛选、关键词搜索、批量取消收藏 |
| F-04 | 已售出/已下架商品在收藏夹中**保留并标记"失效"**（置灰），不可加购、不可下单；客户可手动移除 |
| F-05 | 收藏不影响商品交易，无锁定、无优先购买权 |
| F-06 | 客户不能收藏自己发布的商品 |
| F-07 | 支持购物车多选转收藏（见 C-15~C-17）与收藏夹加购（见 C-18） |

## 3. 订单取消规则

官方定义：订单处于**开始发货状态前**，客户可以取消订单；订单处于**交易完成状态前**，商家可以取消订单。

### 3.1 各状态可取消性矩阵

| 订单状态 | 客户取消 | 商家取消 |
| --- | --- | --- |
| 客户下单 | ✅ 可取消 | ✅ 可取消（必填原因） |
| 商家确认 | ✅ 可取消 | ✅ 可取消（必填原因） |
| 备货完成 | ✅ 可取消（开始发货前最后窗口） | ✅ 可取消（必填原因） |
| 开始发货 | ❌ 不可取消 | ✅ 可取消（必填原因，如客户拒收、发错商品） |
| 交易完成 | ❌ 终态 | ❌ 终态 |
| 已取消 | ❌ 终态，不可重复操作 | ❌ 终态，不可重复操作 |

### 3.2 客户取消规则

| 编号 | 规则 |
| --- | --- |
| X-01 | 客户在客户下单、商家确认、备货完成三个状态可取消订单，取消原因选填（不想买了/信息有误/与商家协商一致等） |
| X-02 | 订单进入开始发货后，客户端取消入口关闭；如仍需终止交易，须与商家线下协商由商家取消 |
| X-03 | 取消成功后商品立即释放恢复在售，订单保留在客户订单列表中标记"已取消"，可追溯 |
| X-04 | 已取消订单**不可恢复**，客户如需购买须重新下单（商品仍在售时） |

### 3.3 商家取消规则

| 编号 | 规则 |
| --- | --- |
| X-05 | 商家在交易完成前任一状态（含开始发货）均可取消订单，**必填取消原因**（商品已线下售出/信息有误/客户拒收/其他） |
| X-06 | 开始发货状态下取消属于异常终止，需向客户明确说明原因，系统记录并通知客户 |
| X-07 | 商家取消同样触发商品释放；频繁取消的商家计入数据看板统计，供运营参考 |
| X-08 | 商家不可操作交易完成订单 |

### 3.4 取消的公共副作用

| 编号 | 规则 |
| --- | --- |
| X-09 | 任何取消发生：① 解除商品锁定、恢复在售；② 写入状态流转日志（含取消方与原因）；③ 通知对方用户 |
| X-10 | 取消操作幂等：重复点击、网络重试不产生二次副作用；与状态推进（确认/发货等）并发冲突时，以先完成的事务为准，后者提示"订单状态已变更，请刷新" |

## 4. 边界与冲突场景

| 场景 | 处理规则 |
| --- | --- |
| 客户 A 下单锁定商品，客户 B 同时加购/下单 | 仅一笔订单锁定成功；B 提示"商品已被抢购"，其购物车中该项转失效 |
| 客户取消与商家发货同时发生 | 以先完成的事务为准：发货先生效则客户取消被拒；取消先生效则发货失败 |
| 商家确认与客户取消同时发生 | 状态机校验前置状态，仅一方生效，另一方返回状态已变更 |
| 商品在收藏夹中被售出 | 收藏记录保留并标记失效，不影响订单流程 |
| 购物车商品下单后订单被取消 | 商品恢复在售但不自动回购物车，避免与"已被他人买走"场景混淆 |
| 多选转收藏时部分商品已收藏/失效 | 已收藏跳过、失效剔除并提示，其余正常转收藏，整批不因此失败 |
| 商家在订单进行中下架/删除商品 | 存在进行中订单（客户下单/商家确认/备货完成/开始发货）的商品禁止下架或删除，须先取消订单 |
