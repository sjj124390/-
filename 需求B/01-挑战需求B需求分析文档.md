## 1. 项目背景

本系统为面向个人闲置交易的二手交易平台，分为**买家端**与**卖家后台**两大模块。前序迭代已完成：

- **迭代一**：用户注册登录、商品发布与管理、商品浏览与详情展示等基础功能，统一页面视觉规范。
- **迭代二**：商品搜索与分类筛选、商品收藏、交易进度追踪、卖家数据看板、意向订单状态统计等增强功能。

当前交易链路为"提交购买意向 → 卖家确认 → 当面验货 → 完成交易"，意向订单仅有**待交易 / 交易成功 / 交易失败**三种状态，存在以下不足：

1. 客户无法批量预选商品，一次购买意向只能对应一件商品，缺少购物车承载；
2. 收藏与购物车之间缺少联动，无法批量转移；
3. 订单状态粒度过粗，无法覆盖"备货、发货"等标准交易环节；
4. 缺少明确的订单取消规则，客户与商家在何种条件下可终止交易、终止后商品如何释放，均无统一约定。

## 2. 挑战需求B 目标与范围

### 2.1 官方需求原文

**B.1 订单升级**
- 系统支持订单管理，订单包括**客户下单、商家确认、备货完成、开始发货、交易完成** 5 个状态；
- 在订单处于**开始发货状态前**，客户可以取消订单；
- 在订单处于**交易完成状态前**，商家可以取消订单。

**B.2 商品预选升级**
- 客户可以收藏商品；
- 客户可以选择商品进入购物车；
- 客户可以从购物车中选择多件商品进行下单；
- 客户可以从购物车中选择多件商品转为收藏。

### 2.2 范围（In Scope）

| 模块 | 需求内容 |
| --- | --- |
| 订单 | 订单创建（购物车多选下单、单品直购）、5 状态顺序流转、已取消终态、交易进度追踪升级 |
| 订单取消 | 客户取消（开始发货前）、商家取消（交易完成前）、取消后商品释放 |
| 购物车 | 加入/移出购物车、失效商品标记、**多选下单**、**多选转收藏**、下单商品锁定 |
| 收藏 | 收藏/取消收藏、收藏夹列表、失效商品展示、与购物车批量联动 |

### 2.3 范围外（Out of Scope）

- 在线支付网关、售后退款仲裁、物流系统对接（发货仅更新订单状态）；
- 订单评价、超时自动取消等官方未要求的扩展能力。

## 3. 角色与核心用例

| 角色 | 核心用例 |
| --- | --- |
| 客户（买家） | 浏览/搜索商品、收藏商品、加入购物车、购物车多选下单、购物车多选转收藏、取消订单（开始发货前）、查看交易进度、确认收货 |
| 商家（卖家） | 管理商品、处理订单（确认 → 备货完成 → 发货）、取消订单（交易完成前）、查看订单统计与数据看板 |

## 4. 功能需求

### 4.1 订单（FR-O）

| 编号 | 需求描述 | 优先级 |
| --- | --- | --- |
| FR-O-01 | 支持两种下单入口：购物车多选下单与商品详情单品直购；选中商品分属不同商家时按商家拆分为独立订单 | 高 |
| FR-O-02 | 订单状态为官方五态：**客户下单 → 商家确认 → 备货完成 → 开始发货 → 交易完成**，另设"已取消"终态 | 高 |
| FR-O-03 | 状态仅允许按序推进：商家确认、备货完成、发货由商家操作；交易完成由客户确认收货触发 | 高 |
| FR-O-04 | 交易进度追踪页按五节点展示：客户下单 → 商家确认 → 备货完成 → 开始发货 → 交易完成 | 高 |
| FR-O-05 | 商家后台意向订单列表升级为订单列表，支持按状态筛选、搜索（商品/客户/手机号）、时间范围查询 | 高 |
| FR-O-06 | 数据看板与订单状态统计同步适配新状态机；历史意向订单按映射规则迁移（见 6.3） | 中 |
| FR-O-07 | 订单关键状态变更（确认、备货、发货、取消、完成）需通知对方用户 | 中 |

### 4.2 订单取消（FR-X）

| 编号 | 需求描述 | 优先级 |
| --- | --- | --- |
| FR-X-01 | 客户在订单处于**开始发货前**（客户下单/商家确认/备货完成）可取消订单；开始发货后取消入口关闭 | 高 |
| FR-X-02 | 商家在订单处于**交易完成前**（含开始发货）可取消订单，需填写取消原因 | 高 |
| FR-X-03 | 订单取消后锁定商品立即释放并恢复"在售"，订单标记"已取消"保留可追溯 | 高 |
| FR-X-04 | 交易完成、已取消为终态，不可再取消或变更；已取消订单不可恢复 | 高 |

### 4.3 购物车（FR-C）

| 编号 | 需求描述 | 优先级 |
| --- | --- | --- |
| FR-C-01 | 客户可将"在售"商品加入购物车；二手单品数量恒为 1，重复加入时提示已在购物车中 | 高 |
| FR-C-02 | 加入购物车**不锁定**商品，商品被他人买走后购物车中该项标记为"失效" | 高 |
| FR-C-03 | 购物车支持单选/全选、按商家分组展示、移除商品 | 高 |
| FR-C-04 | 客户可勾选**多件商品一次提交下单**；提交时系统重新校验商品状态，失效商品不可参与 | 高 |
| FR-C-05 | 客户可勾选**多件商品批量转为收藏**：写入收藏夹并从购物车移除，已收藏的自动跳过 | 高 |
| FR-C-06 | 订单创建成功即**锁定**对应商品，防止一物多卖；下单成功商品自动移出购物车 | 高 |
| FR-C-07 | 订单取消后商品自动解锁，不自动回购物车 | 中 |

### 4.4 收藏（FR-F）

| 编号 | 需求描述 | 优先级 |
| --- | --- | --- |
| FR-F-01 | 客户可对商品收藏/取消收藏，操作幂等，商品详情与列表页心形图标实时同步 | 高 |
| FR-F-02 | 商品详情展示收藏人数（如"已收藏 24 人"），随收藏行为实时增减 | 中 |
| FR-F-03 | 收藏夹支持列表浏览、按分类筛选、批量取消收藏 | 高 |
| FR-F-04 | 已售出/已下架商品在收藏夹中保留并标记"失效"，不可加购、不可下单；收藏夹商品可加入购物车 | 高 |

## 5. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 数据一致性 | 二手商品具有唯一性，下单锁定与状态变更须保证事务性，杜绝超卖与重复成交 |
| 幂等性 | 收藏、加购、取消、状态推进等操作均须幂等，重复提交不产生脏数据 |
| 性能 | 购物车/收藏夹列表查询 P95 < 500ms；订单状态变更实时可见 |
| 可追溯 | 订单保留完整状态流转日志（时间、操作者、原因），供进度追踪与统计使用 |

## 6. 协作约定

### 6.1 与数据库设计（朱江）的衔接

- 新增表：`cart_item`（购物车项）、`favorite`（收藏记录）、`order_status_log`（订单状态流转日志）；
- 订单表升级：状态字段为枚举 `CREATED / CONFIRMED / PREPARED / SHIPPED / COMPLETED / CANCELLED`，新增取消方、取消原因字段；
- 商品表新增锁定标记/锁定订单号，支撑下单锁定与取消释放。

### 6.2 与后端开发（杨接乔）的衔接

- 按 FR 编号提供订单、取消、购物车（含多选下单、多选转收藏）、收藏四组接口；
- 所有状态变更接口须校验前置状态与操作者身份（客户/商家），非法流转返回明确错误码。

### 6.3 历史数据兼容

| 旧意向订单状态 | 迁移目标状态 |
| --- | --- |
| 待交易 | 按当前环节迁移至"客户下单"（未确认）或"商家确认"（已确认） |
| 交易成功 | 交易完成 |
| 交易失败 | 已取消 |

### 6.4 与前端开发（孙俊杰）的衔接

- 页面新增/改造：购物车页（多选下单、多选转收藏）、收藏夹页、订单列表与详情页、交易进度追踪组件（五节点）、商家订单管理页；
- 取消入口按状态与角色动态显隐；视觉沿用现有紫色主题与卡片式布局。

## 7. 验收标准

1. 客户可完成"加购 → 多选下单 → 商家确认 → 备货完成 → 发货 → 确认收货"全流程；
2. 客户在开始发货前可取消订单，开始发货后取消被拒绝；商家在交易完成前可取消，完成后被拒绝；
3. 同一商品被一笔订单锁定后，其他客户无法对其下单，取消后商品恢复在售；
4. 购物车多选转收藏后商品移出购物车，收藏记录不重复；
5. 订单五态按序流转，非法流转被拒绝，状态日志完整；
6. 历史意向订单数据按映射规则正确迁移，看板统计口径一致。
